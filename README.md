# متجر الحلم

متجر عربي RTL مبني بـ React وTypeScript وTailwind CSS، مع Supabase للمصادقة والبيانات والتخزين. تتضمن الواجهة المتجر والأقسام وتفاصيل المنتج ومعرض الصور واختيار اللون والمقاس والخامة، فلاتر البحث والسعر والتوفر والعروض، السلة، التسجيل واستعادة كلمة المرور، الملف الشخصي والعناوين والمفضلة والطلبات وتتبعها. وتشمل لوحة الإدارة مؤشرات المتجر، إدارة المنتجات ومخزون المتغيرات والصور، الأقسام، الطلبات ومراجعة الإيصالات، العملاء، وإعدادات المتجر والسياسات.

## التشغيل المحلي

1. ثبّتي Node.js 20.19+ أو 22.12+.
2. ثبّتي الحزم: `npm install`.
3. انسخي `.env.example` إلى `.env.local` وضعي رابط مشروع Supabase و`anon key` العامة.
4. طبّقي الترحيل `supabase/migrations/20261030000000_initial_schema.sql` على مشروع Supabase.
5. شغّلي `npm run dev`، وللتحقق من نسخة الإنتاج استخدمي `npm run build`.

لا تضعي `service_role` key في تطبيق المتصفح. مفتاح `anon` مخصص للواجهة ويخضع كل طلب لسياسات RLS.

## إعداد المدير

أنشئي حسابًا عاديًا من صفحة التسجيل أولًا، ثم امنحي الحساب دور المدير من SQL Editor في مشروع Supabase بعد استبدال البريد:

```sql
insert into public.user_roles (user_id, role)
select id, 'admin'::public.app_role
from auth.users
where email = 'admin@example.com'
on conflict do nothing;
```

صلاحية المدير تُقرأ من جدول `user_roles` عبر الدالة `public.is_admin()` ولا تعتمد على التخزين المحلي أو قيمة يرسلها المتصفح.

## إعداد الدفع والتوصيل

عدّلي سجل `store_settings` في لوحة SQL أو من صفحة إعدادات الإدارة. مثال إعداد عربون 20% وتوصيل 25 ريال:

```sql
update public.store_settings
set deposit_type = 'percentage',
    deposit_value = 20,
    delivery_fee = 25,
    transfer_details = 'أضيفي بيانات التحويل هنا'
where id = true;
```

يمكن ضبط عربون بمبلغ ثابت عبر `deposit_type = 'fixed'`. تُحسب الأسعار والمخزون والعربون داخل الدالة الآمنة `public.create_order`؛ لا تُعتمد الأسعار المرسلة من المتصفح.

## مخطط البيانات والحماية

ملف الترحيل ينشئ ملفات العملاء والأدوار والأقسام والمنتجات والصور والمتغيرات والعناوين والمفضلة والطلبات وعناصر الطلب وإيصالات الدفع وسجل تغييرات الحالة وإعدادات المتجر. تُفعّل RLS على الجداول وتُنشأ مساحتا `product-images` و`payment-receipts`؛ إيصالات الدفع خاصة ومقيدة بمالك الطلب أو المدير. حساب العميل لا يستطيع تعديل حالة طلبه أو مبلغ الدفع. تُنشأ الطلبات عبر `public.create_order` التي تعيد احتساب الأسعار والعربون وتتحقق من المخزون داخل معاملة قاعدة البيانات، ويعيد إلغاء الطلب المخزون.

## إعداد المحتوى

بعد ربط Supabase وإنشاء حساب الإدارة، أضيفي الأقسام والمنتجات والصور ومخزون كل لون ومقاس، ثم اضبطي بيانات التحويل والتوصيل والتواصل والسياسات من لوحة الإدارة. لا توجد منتجات تجريبية مدخلة في قاعدة البيانات. يجب اختبار إعدادات Supabase والبريد وسياسات التخزين في مشروعك قبل الإطلاق؛ لا يوجد اتصال Supabase مهيأ داخل المستودع ما لم تضيفي ملف `.env.local`.
